Guide

Everything LiveIsland does, and how to set it up. For a quick tour, see the home page.

Install

macOS 14 or later, on Apple silicon or Intel. Run this in Terminal:

curl -fL https://github.com/charonova/LiveIsland/releases/latest/download/LiveIsland.zip -o /tmp/LiveIsland.zip \ && mkdir -p ~/Applications && ditto -xk /tmp/LiveIsland.zip ~/Applications && open ~/Applications/LiveIsland.app

LiveIsland isn't notarized by Apple yet (that needs a paid developer account). Installed with the command above, it opens right away. If you downloaded the zip in a browser, unzip it, move LiveIsland to Applications, open it once, then click Open Anyway in System Settings › Privacy & Security.

To start it with your Mac, turn on Open at login in Settings › General.

Permissions

macOS asks for these the first time each feature needs them. Everything works without them; that feature just stays empty.

PermissionFor
CalendarYour next events, read only
BluetoothAirPods battery
AutomationSpotify and Music (now playing and controls), and Terminal or iTerm2 when you jump to a session
System audio recordingThe live waveform. It only measures the sound, and never records or keeps it

Accounts need no permission: the switchers keep the logins themselves.

Using the island

Point at the notch to open the island (or click it), and move away to close it. When it's closed, clicks pass straight through. It has four tabs, which you can reorder in Settings › Island:

Agents: sessions and limits

Activity: timers, calendar, devices

  • Media: any player, with a real waveform, the cover's glow, scrubbing, ±15 s, Up Next and Recently Played
  • Agents: every Claude Code and Codex session (working, needs you, done, idle). Click one to jump to its window or Terminal tab, or copy its resume command. Rings show each tool's 5-hour and weekly limits
  • Activity: timers, calendar, battery, headphones, microphone and camera
  • Accounts: each account's use, with Switch and Auto (see below)

The most important thing wins the closed notch: a call beats an agent that needs you, which beats music. While music plays, an agent or a timer shares the notch with the waveform.

The Accounts page

Settings › Accounts holds every account. A Claude Code | Codex switch picks the tool. The card under it shows the switcher, its version, the account in use, the last check and Auto; its ⋯ menu checks for updates and opens the switcher's GitHub page. Below the card are three tabs:

  • Accounts: a card per account with 5-hour and weekly bars and reset times. Switch ★ marks the one with the most room. The last card adds an account
  • Automatic: the switch, what the last check found, and the switcher's settings
  • Console: every command and switch, as text

The island's Accounts tab has the same switch, with each tool's Auto button and a shortcut to its console.

Claude Code, with claude-swap

claude-swap (MIT) keeps a login for each Claude account and puts the one in use in place for Claude Code.

  1. Install. Click Install. It runs uv tool install claude-swap, and falls back to pipx, or to Homebrew installing uv.
  2. Add the account you use now with the link at the bottom of the add card.
  3. Add another account. Type a name and click Sign In…. Terminal opens Claude Code's own claude auth login in a folder of its own under ~/.claude-accounts. Once you've signed in, LiveIsland runs cswap add for it.

Each account's menu keeps it out of automatic rotation, renames it, gives it its own switch point, moves it up or down, or removes it. Running Claude Code sessions follow a switch within about 30 seconds.

Don't sign the ~/.claude-accounts folders out later. claude-swap holds the same logins, and signing out cancels them.

Codex, with ccswap

ccswap (MIT) is a fork of claude-swap that adds Codex. LiveIsland installs it next to claude-swap without changing it, and runs only its Codex commands, with its data in LiveIsland's own folder. claude-swap's accounts and settings stay as they are.

  1. Install runs uv tool install ccswap.
  2. Add the account Codex uses now.
  3. Sign In… opens codex login in a temporary folder, adds the account to ccswap, then deletes the folder.

A Codex account's menu redeems a banked reset (it asks first) or removes the account. Codex reads its login when it starts, so after a switch, restart a running session with codex resume.

Automatic switching

Turn on Auto, on the card or in the island. LiveIsland then runs cswap auto --json or ccswap codex auto --json, restarts it if it ever stops, and shows each switch in the notch. The Automatic tab holds each switcher's own settings, so changing one here is the same as config set:

claude-swapccswap (Codex)
Switch point5-hour and weekly, separatelyOne threshold
TimingWait between switchesCheck interval, and wait between switches
PickThe most room, or the soonest weekly resetThe most room
Neither Anthropic nor OpenAI says whether switching your own accounts automatically is allowed. Anthropic's Consumer Terms forbid "bypassing any of our systems or protective measures", and Claude Code's limits assume "ordinary, individual usage". Auto stays off until you turn it on, and accounts that bill an API key stay out of rotation.

The console

The console shows every command LiveIsland ran, with its full output and exit code, and every switch, refusal and restart as it happens. Tick Show every check to also see the minute-by-minute checks. Type any other command at the bottom: it runs the switcher directly, never through a shell. The Codex console runs only Codex and settings commands. For Claude, Dashboard opens claude-swap's own dashboard in Terminal.

Claude Code's limits

Claude Code shares its 5-hour and weekly percentages only with its status line. In Settings › AI Agents, click Add to My Status Line. LiveIsland adds three lines to your status line script, after it reads its input, and keeps a copy of the original next to it (*.liveisland-backup). To add them yourself, they're in scripts/claude-statusline-snippet.sh. Without them, LiveIsland still counts Claude Code's tokens from its transcripts. Codex writes its limits into its sessions, so it needs nothing.

Updates

Settings › Software Update shows the version you have, and whether a newer one is out on GitHub, with what's new. Update Now downloads it and checks it: the SHA-256 must match, it must be LiveIsland at the promised version, and its signature must verify. It then replaces the app and reopens it. LiveIsland checks once a day, which you can turn off, and never installs on its own. To update claude-swap or ccswap, use ⋯ › Check for Updates on the Accounts card.

Privacy

  • No analytics, no account. Transcripts, calendar events and everything else stay on your Mac.
  • LiveIsland never reads a login. claude-swap keeps Claude's logins in your Keychain, and ccswap keeps Codex's as private files in LiveIsland's folder. The console lives only in memory.
  • Network requests: Spotify's cover art, and one GitHub check a day for updates. The switchers ask Anthropic and OpenAI for each account's use, as they do on their own.

Troubleshooting

"Apple could not verify LiveIsland"

It isn't notarized yet. Open it once, then click Open Anyway in System Settings › Privacy & Security, or install it with the Terminal command above.

A switch happened but Codex still uses the old account

Codex reads its login only when it starts. Restart the session with codex resume.

The switch point shows 90% but I set 95%

claude-swap and ccswap keep separate settings. Set each one on its own Automatic tab.

An account says "Sign in again"

Its saved login stopped working. Remove it, then add it again with Sign In…. Avoid claude auth logout and codex logout on accounts a switcher holds.

The waveform doesn't move

Allow System audio recording when macOS asks; a new build may ask again. Without it, the island shows an animated symbol. You can turn the waveform off in Settings › Media.

No limits for Claude Code

Add LiveIsland's lines to your status line (see Claude Code's limits). The numbers appear after Claude Code's next reply.

Build from source

You need the Xcode Command Line Tools and CMake (brew install cmake, for the media adapter):

git clone https://github.com/charonova/LiveIsland.git && cd LiveIsland ./scripts/install.sh # builds, copies to ~/Applications and launches ./scripts/test.sh # runs the tests
