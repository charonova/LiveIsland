The problem

You walk away. Forty minutes later, it has stopped.

You hand Claude Code or Codex a long job. It hits a limit, and nothing moves until you come back, sign in to another account and type "continue". If you pay for more than one account, the others sat idle the whole time.

You've hit your session limit · resets 3:45pm

Without LiveIsland

  • The agent stops until you notice
  • Log out, log in, guess which account has room
  • What the switcher did is hidden in a terminal
  • Check every window to see which agent needs you

With LiveIsland

  • It moves to the account with the most room before the limit
  • Every account's 5-hour and weekly use, side by side; one click to switch
  • A console with every command, check and switch
  • The notch says who needs you, and jumps to the right tab
What it does

Everything your notch should have been doing.

Claude Code Codex

Switches before you hit the wall

LiveIsland runs two open-source switchers for you: claude-swap for Claude Code and ccswap for Codex. Each checks every account once a minute and moves to the one with the most room when the account in use nears your switch point.

  • Install and update them in one click
  • Add accounts with each tool's own sign-in; the one in use stays as it is
  • Your switch points for the 5-hour and the weekly limit
  • Off until you turn it on
Nothing hidden

See every command and every switch

The console shows each command LiveIsland runs, with its output and exit code, and every check and switch as it happens. Type your own commands there too. LiveIsland never reads a login: the switchers hold them.

Agents

Who's working, who needs you

Every Claude Code and Codex session: working with a timer, waiting for you, done or idle. Jump to the exact Terminal tab or editor window, and see both tools' real 5-hour and weekly limits as rings.

Media

A real waveform, from any player

Now playing from Spotify, Music, browsers and anything else, with a waveform that moves to the music, a glow from the cover, scrubbing, Up Next and Recently Played. While music plays, an agent can share the notch with it, like the iPhone.

Install

One command, then three steps.

curl -fL https://github.com/charonova/LiveIsland/releases/latest/download/LiveIsland.zip -o /tmp/LiveIsland.zip \ && mkdir -p ~/Applications && ditto -xk /tmp/LiveIsland.zip ~/Applications && open ~/Applications/LiveIsland.app

Not notarized by Apple yet. Installed this way it opens right away; from a browser download, use Open Anyway in System Settings › Privacy & Security. Later versions install from Settings › Software Update.

Install the switcher

Settings › Accounts, pick Claude Code or Codex, click Install.

Add your accounts

Type a name, click Sign In…. The tool's own sign-in opens; the account in use stays as it is.

Turn on Auto

It switches before the account in use runs out. Watch it from the island or the console.

⚠️ Neither Anthropic nor OpenAI says whether switching your own accounts automatically is allowed. Anthropic's Consumer Terms forbid "bypassing any of our systems or protective measures". Auto stays off until you turn it on. Keep it to accounts you pay for.
